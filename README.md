# 六级二十分 · 0.3 扩展版

## 免费静态托管路线（新增）

手机联网获取公共素材可使用免费静态托管，不必购买一直运行的服务器。已提供 GitHub Pages 与每日 Actions 发布配置，见 FREE-HOSTING.md；先注册账号，再将本目录内容上传到仓库根目录并开启 Pages。当前还未在用户账号中执行，不能称为已上线。以下 Node/Docker 说明是另一条运行服务器的路线，其“静态目录不能抓取”指手机直接运行抓取接口；定时任务可在发布前抓取，手机只下载生成好的素材包。

手机、平板、电脑共用的 PWA。20 分钟综合训练、4,000 词主训练、5,404 词全量扩展、19 组离线表达素材。无第三方运行依赖。

**当前状态：可本地运行。公网 HTTPS 部署未完成，外部新闻抓取未验证成功。每日联网模块已用受控数据测试，不代表云端每日新编语料服务已经上线。**

## 运行

需要 Node.js 22 或以上。解压后进入本目录，运行 `node server.cjs`，浏览器打开 http://localhost:4173。端口占用时在 PowerShell 设置 `$env:PORT='4174'` 再启动。首次等待“离线资源已就绪”。不要双击 HTML。

手机的 localhost 指手机自身，不能连接电脑。临时预览可设 `$env:HOST='0.0.0.0'`，同一 Wi-Fi 下访问电脑局域网 IP；普通 HTTP 局域网地址通常不能安装 PWA 或使用离线缓存。

## 手机和平板如何更新

正式使用需要将整个 Node 服务部署在始终运行的云端，手机和平板打开同一 HTTPS 网址。电脑不用开机，云端服务必须运行且可访问媒体。**只上传 dist 静态目录不能提供新闻抓取、每日筛选和公共素材持久化。**

本包有 Dockerfile，在具备 Docker 的服务器运行：

```text
docker build -t cet6-twenty .
docker run -d --restart unless-stopped -p 8080:8080 -v cet6-materials:/data cet6-twenty
```

这些命令不会自动购买云资源、配置域名或开通 HTTPS。需要 HTTPS 入口转发到 8080、持久化卷保存公共素材。部署后真实检查 `/daily-feed.json`、`/api/library/status`、`/api/news`，再用手机验证。

客户端在打开、恢复联网、返回前台时检查更新，前台每五分钟再检查。手机后台不保证联网，所以不是关闭程序仍即时推送；打开时下载即可。离线继续使用已保存的内容。更新不替换当前训练轮次的题目和作答。

Android Chrome：菜单 → 安装应用 / 添加到主屏幕。iPhone / iPad Safari：分享 → 添加到主屏幕。首次缓存包括应用、词库、素材和全部音频。

## 来源与六级筛选

|来源|当前用途|
|---|---|
|人民网文化、教育、科技公开栏目|中文文章标题和链接；转载稿不自动标为人民日报原稿|
|BBC News Education、Science & Environment 官方 RSS|英文选题线索，保留完整标题与 BBC 来源链接|
|WHO 官方 RSS|补充公共议题，仍需通过主题筛选|

news.cjs 配置固定来源，不提供任意网址代理、不向媒体上传作答。栏目结构及 RSS 可能变化，需要部署后验证。BBC RSS 用于个人学习，商业使用需另行核对媒体授权。

curation.cjs 规则：文章链接须属于允许媒体域名，日期可识别且在近七天；选文化历史、教育学习、绿色发展、科技生活、社会公共服务，排除战争伤亡、猎奇、治疗与炒股推荐等。按主题匹配数和新近程度选择最多 12 条线索，关联最多 3 组每日练习。这是备考选题规则，**不是历年真题概率模型或热点命题预测**。

自动流程：抓标题 → 筛主题 → 关联已有原创练习 → 保存发布。关联题明确标为“不是该报道的翻译”，不根据标题编造报道事实。每天更换新闻选题，**不等于每天新创作、核验一篇新闻译文**。后者需要编辑审核流程或生成服务加审核，本版未接入生成服务。

服务启动时检查更新；之后每 15 分钟检查，北京时间 08:00 后当日成功一次。失败至少间隔 15 分钟重试，保留上次成功素材。公共包保存在 DATA_DIR/pack.json，状态在 DATA_DIR/status.json，默认本目录 data。服务重启读取旧结果。多个服务器实例需要数据库与更新协调，本版支持单实例。

## 词库和初始素材来源

词库基于 [ECDICT](https://github.com/skywind3000/ECDICT)，采用 [WordTyper CET-6 派生数据](https://github.com/grhliu/wordtyper-vocabularies)（5,371 条，标记更新时间 2026-07-27），清理、去重并与 150 个编辑词条合并，共 5,404 个独立词条。默认选择 4,000 词，也可全量学习。逐词来源见 VOCABULARY-SOURCES.json，MIT 授权文本见 dist/LICENSE-DATA.txt。

这是社区备考词库，**不是官方完整必考词表，4,000 词也不是精确真题频率排名**。主训练兼顾各字母范围。150 个编辑词条有原创例句，其余多数只有音标与释义；缺例句时明确提示，可写自己的例句或查询 Free Dictionary API。联网词典需要实际网络可用。

19 组初始素材来自 UNESCO、IEA、WHO、FAO、联合国公开资料，以及人民网科技栏目 2026-10-06 的 AI 课堂观点改编和原创情境。每题有来源网址、来源日期、核验日期、改编说明。学习建议、写作任务、范例多数为原创教学延伸。人民网条目依据可检索报道摘要核对，未复制全文。BBC 目前只提供候选新闻，没有已核验的 BBC 报道改编题。

听力是 3 组原创情境、6 段 Microsoft Zira Desktop 合成 WAV（全文与目标句），不是 BBC 原音或历年真题录音。

## 20 分钟训练

|阶段|时间|任务|
|---|---:|---|
|词汇|7 分钟|到期优先，最多 20 个复习 + 10 个新词，评分、语境回忆；缺例句时标注词义回忆|
|听力|7 分钟|全文、目标句、变速、听写、同义替换|
|翻译写作|4 分钟|短译、40–60 词短写、参考句式与自检|
|回顾|2 分钟|薄弱词、复习日期、句式回忆与笔记|

正式六级包含段落翻译；短译与短写是碎片练习，素材拓展区支持完整段落练习。每次输入、选择、评分保存，计时每秒保存；后台、关页暂停，重开恢复答案、题目、播放位置与计时。听写反馈是词序匹配，不是正式考试评分。

## 多端、多用户、存储

|问题|实际能力|
|---|---|
|多端使用|响应式 PWA；部署后各端访问同一网址，获取同一公共素材|
|多个用户|各设备独立保存；同一浏览器最多 30 个学习档案，无密码，不是登录账户|
|进度跨端|JSON 导出 / 导入迁移；自动云同步未实现|
|答案与计时|浏览器 localStorage，按本设备档案分开，不上传服务器|
|离线资源|Service Worker Cache Storage：页面、词库、素材、音频，每端独立|
|公共素材|服务器持久化 JSON，不含用户作答|

清理浏览器数据、无痕模式、系统回收可能丢失记录，请定期导出备份。换浏览器、设备、网址不会自动继承进度。备份包含当前档案的词汇记录、答案、计时、素材草稿；导入替换当前档案，先备份。真正的云账号及同步设计见 SYNC-DESIGN.md，设计不代表已实现。
